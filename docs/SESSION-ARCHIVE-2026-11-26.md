## 一、项目缘起与史实核实

用户提出村庄为「河北省邯郸市肥乡区南翔公庄村」，村中有历史名人，希望为其做一个介绍网站。经查证：

- **标准村名**：河北省邯郸市肥乡区大寺上镇**南相公庄村**，"翔"应为"相"。
- **历史名人**：**李沆（947—1004）**，字太初，洺州肥乡人。太平兴国五年（980）进士，曾任太子宾客、为宋真宗之师；咸平初以户部侍郎、参知政事拜同中书门下平章事、监修国史。卒谥「文靖」，赠太尉、中书令，史称「**圣相**」，配享真宗庙庭，宋仁宗时从祀孔子庙庭。
- **村名由来**：隋唐时此地称「河凤乡」；因李沆拜相（古称宰相为「相公」），村以人显，改名相公庄，后按方位分为南、北相公庄。
- **方志依据**：民国二十九年《肥乡县志》卷三十七：「南相公庄为李文靖公故里」。1984 年《肥乡县地名志》亦记「宋宰相李沆生于此村，为纪念他，故称相公庄」。
- **重要考据**：杨亿《武夷新集》所载《李沆墓志铭》记其归葬「河南府洛阳县贤相乡积润里」，可订正县志「李文靖墓，旧在城西门外」之说；王禹偁《小畜集》所载父李炳墓志（连标题 848 字）可复原李氏世系。
- **易混项（务必避开）**：窦默（1196—1280）是肥乡镇城西村人，非本村；山东济南章丘「相公庄街道」是房玄龄故里，与本村同名异地。

**核实来源**：
- 肥乡区政府《著名人物》：https://www.fxq.gov.cn/zjfx/zsyz
- 肥乡区政府 2017 年人大建议答复：https://www.fxq.gov.cn/ztzl/cbjyta/201709/t20170922_1709837.html
- 博雅地名网 · 南相公庄村：http://www.tcmap.com.cn/hebei/feixiangxian_daxihanxiang_nanxianggongzhuangcun.html

## 二、参考站点调研与选型

### 第一轮：中文村落 / 名人故里站点

传统村落数字博物馆、博雅地名网、文史淮安、国家文物局公共信息服务、国家地名信息库、中国方志网等。其中传统村落网抓取被 403 拦截，古村之友已无法访问，广东数字村史馆无独立网址（走小程序）。

用户随后明确调整方向：**要大气、世界级的网站，乡土风格不要**。

### 第二轮：国际级机构站点

| 站点 | 参考价值 |
|---|---|
| Monticello（杰斐逊故居） | 世界遗产 + 研究所，大图叙事、多线并行，信息架构最完整 |
| Mount Vernon（华盛顿故居） | 全宅虚拟漫游、数字历史中心 |
| 魏玛古典基金会 | 一个品牌统管 31 处场馆、12 处世界遗产，把人物升维成城市精神史 |
| 莎士比亚出生地信托 | 一处机构统管 5 座故居，名人故里 IP 化范本 |
| 贝多芬故居（波恩） | 手稿数字化档案库 |
| 莫扎特出生地、巴黎雨果故居、甘地遗产门户 | 文献门户、统一视觉系统 |
| Google Arts & Culture、National Trust、English Heritage、UNESCO 世界遗产中心 | 平台级技术与权威框架 |
| **孔子博物馆（曲阜）** | 国内少数完全不走乡土风的名人故里馆，以人物思想立站 |

### 选型结论

1. **走「历史名人故里」而非「村」这条线**：村本身是华北平原的普通农业村（245 户、850 人），全部辨识度都来自李沆，连村名都因他而改；按「村」去做必然滑向村容、物产、民俗，回到被否掉的乡土风。
2. **单一参考站选孔子博物馆**：李沆故居与墓葬均不在村里，没有实体大宅、没有藏品可拍，Monticello / Mount Vernon 那套靠真实宅邸撑起来的做法会变成空壳大图。孔子博物馆是唯一「以人物思想立站」的大气范例，陈列按「时代 / 一生 / 智慧 / 与中华文明 / 与世界文明」展开，可直接平移；李沆从祀孔庙，气质相合。
3. **组合方案**：叙事骨架用孔子博物馆；视觉与信息架构借 Monticello；内容厚度借甘地遗产门户的文献全文数字化；中国传统村落数字博物馆只借八个板块作村情底稿，视觉不借。

## 三、首页原型

深墨底 + 哑金细线 + 大字号宋体标题，全屏 Hero 用抽象地平线与淡金圆日，右侧巨大「相」字水印；深色叙事段与米白展墙段交替。走现代博物馆展墙的路子，不仿古、不村史馆。

**栏目框架**：
1. 首页：全屏主视觉 +「一座因宰相得名的村庄」+ 核心数据条
2. 千年一村：河凤乡 → 相公庄 → 县志立证 → 今日，横向时间轴 + 史料订正框
3. 李沆其人：947—1004 大数字 + 五段年表
4. 圣相之治：焚诏 / 无口匏 / 知人三张卡片，逐条标出处
5. 文献典藏：四条文献可展开节录，可全文检索（规划）
6. 故里风物：邯郸地标图版
7. 今日相公庄 / 研究与参与：村情、征集、大事记

**史料处理原则**：引文一律标出处；白话转述标「语译」；未录入全文的注明「待录入」；节录注明「示意，正式版依点校本校对」。全站不写「李沆墓在村」，反而把墓志铭订正县志做成考据亮点。

## 四、域名与部署决策

### 域名可用性实测

- **已注册**：`lihang.com` / `.org` / `.net` / `.cn` / `.com.cn`、`shengxiang.com` / `.cn`、`wenjing.org`
- **查无记录（可尝试注册）**：`lihangheritage.com` / `.org` / `.net` / `.cn`、`lihangmuseum.com` / `.org`、`chancellorvillage.com` / `.org`、`xianggongzhuang.com` / `.cn`、`feixiangheritage.com` 等
- **主推**：`lihangheritage.com`，与品牌 LI HANG HERITAGE 一致，纯字母、无连字符数字；结构上照「人名 + Heritage」的国际机构命名
- **明确不用**：超长村名拼音（`nanxianggongzhuang.com`）、`.museum`（需博物馆资质审核）、`.gov.cn`（仅限县级以上政府机关及承担行政职能事业单位，村委会 / 村集体不能申请）、`.io` / `.ai` / `.app`（不能备案）

### 用户决定：不备案，境外域名 + 境外服务器

- **澄清的误解**：备不备案只看服务器在哪，与域名在哪买无关；解析到境外服务器无需 ICP 备案，但面向境内公众提供内容时，内容合规义务不因服务器在境外而消失。
- **域名组合调整**：去掉 `.cn` / `.com.cn` / `.中国`（CNNIC 实名规则绕不开），改为主 `lihangheritage.com` + `lihangheritage.org`（英文站 / 镜像），`.net` 可选。
- **合规设计**：不设在线投稿与评论区，征集走线下登记与邮件，避免交互式功能带来的额外责任。
- **托管建议**：首选 Cloudflare Pages / Workers 静态资源（免费、自动 HTTPS）；访客主要在村里时，中国香港 / 新加坡轻量 VPS 更实在。不建议 Vercel / Netlify / GitHub Pages 作大陆主力。
- **三个代价**：微信内未备案域名常被拦截或弹风险提示；国内 CDN、微信支付、小程序业务域名、百度收录不可用；将来申报文旅项目或要官方背书时，未备案会成为硬伤。**但纯静态站迁回国内几乎零成本，此决定可逆。**

## 六、配图

### 史实前提

**李沆没有传世写真**，宋代名相多数如此，坊间「李沆像」基本是后世想象画或现代 AI 图。丛台、赵武灵王（战国）、响堂山石窟（北齐）比李沆早数百年到千余年，广府古城现存城墙主要是明清遗存——页面专门加了「时代说明」，明确图版只是地域文脉，**并非李沆生活时代的场景或遗迹**。

### 过程

1. 出图服务连续三次网络故障，未生成 AI 图、未消耗积分。先用公有领域（传）宋徽宗《文会图》作「北宋士大夫时代意象」，明确标注非李沆肖像，并写「史无写真，故不立像」。
2. 用户随后提供三张**李沆艺术再现像**（设色半身像、半身白描稿、全身立像），要求改用。口径随之改为「**史无写真，以像存意**」，明确标注「艺术再现，非史实肖像、不作容貌依据」。《文会图》移除。
3. 三图压为 WebP（共约 516 KB），另生成缩略图与 1200×630 的 OG 分享封面（深墨底 + 人像 + 标题）。
4. 邯郸地标素材全部取自 Wikimedia Commons 自由授权（CC0 / CC BY-SA 4.0 / 公有领域），授权清单存 `assets/credits.json`，页面有可展开的完整署名。统一做灰度 + 降饱和 + 暗化，避免彩色旅游照的乡土感。
5. 剔除两张误下素材：Commons 上 `ChinaHandanCongtai.png` 实为丛台区**区位地图**、`Guangfu.png` 为古城**规划平面图**，均非建筑照片。

**最终图版**：Hero 背景武灵丛台夜景（CC0）；赵武灵王塑像·胡服骑射（CC BY-SA 4.0）；武灵丛台日景（CC0）；广府古城城墙（CC BY-SA 4.0）；响堂山石窟佛像（CC0）。

## 七、微信群分享优化

**判断**：微信分享卡片要靠微信服务器抓取网页信息，未备案的 `github.io` 抓取常失败，群里最终只显示一行蓝色链接文字；自定义卡片需认证公众号 + 已备案域名，现阶段不可行。因此主推**发图 + 二维码 + 现成文案**，而不是继续优化链接卡片。第三方短链更易被判风险、不可控，不用。

**交付四件套**（均在 `share/`）：
- `wechat-poster.jpg`：1080×1760 竖版主海报，李沆像 + 县志引文 + 三组数据 + 二维码
- `wechat-long.jpg`：内容长图，四段核心内容，不点链接也能读完
- `qrcode.png`：独立二维码
- `wechat-copy.txt`：群里版 / 简短版 / 正式版 / 一句话版文案 + 操作步骤

**站点同步**：补 `itemprop` 元信息（微信 / QQ 抓取器会读）、`format-detection=telephone=no`（顺带避免区划代码被识别成电话号码）；微信 UA 下底部浮出「点右上角 ··· → 在浏览器中打开 / 发送给朋友」引导；页脚加「复制本页链接」「下载分享海报」「下载内容长图」。三张图中的二维码经解码实测均正确指向线上地址。

## 八、事实更新：村里故居文化馆已落成

用户告知「现在村里建了故居文化馆了」。这是项目事实的重要更新，此前「村内无李沆故居 / 墓葬实体遗存」指的是**宋代原生遗存**，该考据不变；新建文化馆是**当代纪念与展示场馆**，不可写成李沆故居真迹或宋代原址。

**文案口径**：从「因为没有遗存，只能靠文献」换成「**实体馆陈列其形，本数字馆存其文献……两相参证**」，标题「以文献立馆」保留。用户未提供馆的正式名称、落成时间、面积等信息，站内一律用泛称「故居文化馆」，不编造具体名称与年份。

同步改动四处：`#archive` 章节导语（中英）、`#today` 章节导语（补记文化馆落成，中英）、页脚表述、分享长图 04 章。墓志铭记归葬洛阳、站内「不将墓葬系于本村」的史料订正框原样保留。
